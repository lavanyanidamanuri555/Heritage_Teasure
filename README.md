🌍 Heritage Treasures – UNESCO World Heritage Sites Analysis

An interactive data visualization project that transforms the UNESCO World Heritage Sites dataset into meaningful insights using Tableau.

📌 Project Overview

The UNESCO World Heritage dataset contains rich information about globally recognized cultural and natural sites.
However, in its raw tabular format, it is difficult to interpret and analyze.

This project converts the dataset into:

📊 Interactive visualizations

🎛 Insightful dashboards

📖 Story-driven analytics

to help users understand:

Global heritage distribution

Endangered sites

Regional growth trends

Category-wise contribution

Future inscription forecasting

🎯 Objectives

Analyze heritage site distribution across regions and countries

Identify sites that are “In Danger”

Study historical inscription trends

Compare Cultural, Natural, and Mixed sites

Forecast future heritage growth
